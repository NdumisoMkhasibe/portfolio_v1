# Ndumiso Mkhasibe — Portfolio

A responsive personal portfolio built with React, TypeScript, and Vite. It presents three selected projects, software engineering studies, technical skills, prior electrical technician experience, and contact links.

FumanAI is presented as one selected project; the only design element borrowed from it is its charcoal, warm cream, and restrained gold colour palette. The portfolio's identity, content, artwork, and layout follow Ndumiso Mkhasibe's brief and the supplied reference.

## Run locally

```bash
npm install
npm run dev
```

## Check and build

```bash
npm run lint
npm run typecheck
npm run build
```

The production files are written to `dist/`. The project is ready to connect to Vercel as a Vite app.
